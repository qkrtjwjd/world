- 도자기 손가락 딱 소리 없음 (`ceramic_tap` 클립이 비어 있음)

설계돼 있던 데이터가 이제 실제로 뜹니다.

| | 현실 | 환상 |
|---|---|---|
| 마시멜로 | 체력 +10 · 정신 −5 | 체력 +30 · 정신 +5 |

`realityDescription` 도 3개(아네모네 · 핫초코 · 마시멜로)에 원고가 있습니다.
**필드와 데이터는 하나도 지우지 않았습니다.**

> ⚠ **F키를 눌러 현실을 볼 때 아이템 효과가 달라집니다.** 이전에는 항상 환상 쪽이었습니다.

### 금지 이름을 추가하려면

`ForbiddenNames.json`에 항목 하나를 추가하면 끝입니다. **코드도 유니티도 건드릴 필요 없습니다.**

```json
{ "id": "새캐릭터", "policy": "block", "aliases": ["새캐릭터", "newchar"], "line": "그 이름은 안 돼." }
```

`policy`는 `"block"`(거부) 또는 `"allow"`(한마디 하고 통과 — 이스터에그)입니다.
공백·구두점·대소문자는 자동으로 무시되므로 `"세 라"` `"SERA"`는 `sera` 하나로 전부 걸립니다.

### 대사에서 이름 쓰는 법

```yarn
{$이름}: 대사입니다              // 화자 이름
{이름조사("가")} 잠에서 깬다      // 받침에 따라 이/가 자동 선택
{$이름}의 손목                   // 받침과 무관한 조사는 변수 + 원문
```

`<<showSprite "루" ...>>`의 `"루"`는 **조회 키라서 그대로 둡니다.** 표시 이름과 무관합니다.

> `SolTradeUI` 컴포넌트를 `panel` 자기 자신에 붙여도 됩니다. 대사 재생 중에는 패널을 껐다 켜는데, 대사 코루틴은 `YarnDialogue`의 상주 호스트에서 돌기 때문에 패널이 꺼져도 끊기지 않습니다.

| 필드 | 내용 |
|------|------|
| `panel` | 루트 패널 |
| `choiceGroup` + `talkButton` / `tradeButton` | 대화 / 거래 선택 단계 |
| `tradeGroup` + `slotContainer` | 품목 목록. `GridLayoutGroup` 권장 |
| `openSlotPrefab` | **Button + Image(아이콘) + TMP_Text(이름)**. 아이콘 Image는 **루트가 아니라 자식**에 두세요 (아래 주 참조) |
| `coveredSlotPrefab` | 천으로 덮인 칸. Button이 있어도 리스너를 붙이지 않아 무반응입니다 |
| `itemFocusGroup` + `focusIcon` / `focusNameText` / `focusDescriptionText` | 품목 상세 |
| `offerContainer` + `offerSlotPrefab` | 루의 소지품. **Button + Image(자식) + TMP_Text(개수)** |
| `hiddenNameLabel` / `hiddenDescriptionLabel` | 마을에서 이름·설명 자리에 넣을 표기. **비워두면 아무것도 안 뜹니다** |
| `backKey` | 이전 단계 복귀 키 (기본 `Q`). 취소 키는 설정의 일시정지 키를 따릅니다 |

> ⚠️ **마을 품목 버튼을 회색(`interactable=false`)으로 만들지 마세요.** 선택은 정상 동작하고 성립만 막히는 것이 정본 기준입니다. 코드도 그렇게 돼 있습니다.
> ⚠️ **가격·수치·등급을 표시하는 요소를 만들지 마세요.** 잔액·통화·되판매 개념이 이 게임에 없습니다.
> ℹ️ **아이콘 Image 위치** — 슬롯 프리팹 루트에는 보통 Button의 배경 Image가 있습니다. 코드는 **자식에 있는 Image를 우선**해서 아이콘을 넣고, 자식이 없을 때만 루트를 씁니다. 아이콘을 자식 오브젝트로 두면 배경이 아이콘으로 덮이는 사고가 없습니다.

**15-4. SFX 이름 배선**
