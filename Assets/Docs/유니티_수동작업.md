`saturationVolume` 이 **미배선이라 화면에 드러나지 않았을 뿐**이고, 1-C 에서 Volume 을 연결하는 순간
기본 설정만으로 화면이 과채도가 됐다.

→ **`0 = 흑백 / 1 = 원본`** 으로 고쳤다. 근거는 설정 패널 쪽에 있다 — 슬라이더 이름이
「색채 **강도** (채도)」이고 퍼센트로 표시되며, 같은 패널의 다른 「강도」 슬라이더(볼륨 6종 ·
글리치 효과 강도)가 **전부 100% = 기본값**이다.

> ⚠️ 부수 효과로 **과채도(+100)로 올리는 기능은 사라졌다.** 이 게임은 채도 자체가 이야기의
> 언어라(환상/현실 필터 · 인형화 30~69 구간 회색화) 접근성 슬라이더가 그 위로 올라가면
> 연출과 싸운다. 되돌리지 말 것 — 코드 주석에 같은 내용을 적어 뒀다.
>
> **밝기는 그대로 0.5 가 기본이다.** 어둡게도 밝게도 가야 하므로(−2EV ~ +2EV) 불일치가 아니다.

**15-3. SolTradeUI 프리팹 제작** ⭐ 가장 오래 걸립니다

Canvas 하위에 Panel을 만들고 `SolTradeUI` 컴포넌트를 붙입니다. 기존 `MerchantUI` 프리팹은 **존재한 적이 없으므로 전부 새로 만들어야 합니다.**

> `SolTradeUI` 컴포넌트를 `panel` 자기 자신에 붙여도 됩니다. 대사 재생 중에는 패널을 껐다 켜는데, 대사 코루틴은 `YarnDialogue`의 상주 호스트에서 돌기 때문에 패널이 꺼져도 끊기지 않습니다.

| 필드 | 내용 |
|------|------|
| `panel` | 루트 패널 |
| `choiceGroup` + `talkButton` / `tradeButton` | 대화 / 거래 선택 단계 |
| `tradeGroup` + `slotContainer` | 품목 목록. `GridLayoutGroup` 권장 |
| `openSlotPrefab` | **Button + Image(아이콘) + TMP_Text(이름)**. 아이콘 Image는 **루트가 아니라 자식**에 두세요 (아래 주 참조) |
| `coveredSlotPrefab` | 천으로 덮인 칸. Button이 있어도 리스너를 붙이지 않아 무반응입니다 |
| `itemFocusGroup` + `focusIcon` / `focusNameText` / `focusDescriptionText` | 품목 상세 |
| `offerContainer` + `offerSlotPrefab` | 루의 소지품. **Button + Image(자식) + TMP_Text(개수)** |
| `hiddenNameLabel` / `hiddenDescriptionLabel` | 마을에서 이름·설명 자리에 넣을 표기. **비워두면 아무것도 안 뜹니다** |
| `backKey` | 이전 단계 복귀 키 (기본 `Q`). 취소 키는 설정의 일시정지 키를 따릅니다 |

> ⚠️ **마을 품목 버튼을 회색(`interactable=false`)으로 만들지 마세요.** 선택은 정상 동작하고 성립만 막히는 것이 정본 기준입니다. 코드도 그렇게 돼 있습니다.
> ⚠️ **가격·수치·등급을 표시하는 요소를 만들지 마세요.** 잔액·통화·되판매 개념이 이 게임에 없습니다.
> ℹ️ **아이콘 Image 위치** — 슬롯 프리팹 루트에는 보통 Button의 배경 Image가 있습니다. 코드는 **자식에 있는 Image를 우선**해서 아이콘을 넣고, 자식이 없을 때만 루트를 씁니다. 아이콘을 자식 오브젝트로 두면 배경이 아이콘으로 덮이는 사고가 없습니다.

**15-4. SFX 이름 배선**

`SolTradeUI`의 `sfxOpen` / `sfxSelect` / `sfxBack` / `sfxTradeSuccess` / `sfxTradeReject`는 **비어 있는 채로 출고**했습니다. **`AudioManager`에 이미 등록된 이름 중에서만** 골라 넣으세요(4번 항목 참조). 비워두면 무음이고 에러는 나지 않습니다.

**15-5. SeraApproachTrigger 배치**

1. 솔 구역에 빈 GameObject + **Collider2D (Is Trigger 체크)**
2. `SeraApproachTrigger` 컴포넌트 추가
3. `seraTag` / `seraLayer`로 세라를 식별하도록 지정
4. `onSeraApproach` → 씬의 `SolTradeUI` 오브젝트를 드래그 → **`SolTradeUI.ForceClose()`** 선택

### 확인 방법

1. 마을에서 솔에게 E키 → 대화 / 거래 선택창
2. **거래** → 품목 목록. 덮인 칸이 `coveredSlotCount`만큼 보이고 **클릭해도 무반응**
3. 품목 하나 선택 → 이름·설명이 **안 보이고**(마을) 루의 소지품이 같은 화면에 뜸
4. **각설탕 선택 → 창이 유지된 채 루 독백 노드가 호출되고 거래는 성립하지 않음**
5. `backKey`(기본 Q) → 대화/거래 선택창으로 복귀 / ESC → 전체 종료
6. 세라를 `SeraApproachTrigger` 안으로 이동 → **확인창 없이 즉시 닫힘.** 다시 열면 목록 처음부터
7. 숲(`ForestTrade`)에서 → 이름·설명이 뜨고, `forest_currency_tmp` 제시 시 성립 + 인벤토리 증감
8. 숲에서 각설탕 제시 → `GradeMismatch` 노드 호출

### 시선 추종

`followFacing` ✔. 시선의 출처는 둘이다.

1. **`SeraVision`** 이 있으면 그쪽 `facing` 이 단일 출처다 (마을).
2. 없으면 **Animator 의 `dir`** (0=아래 1=옆 2=위) 과 **`localScale.x` 부호**로 유추한다 (집).
   부호 규약은 루·세라 공통 — **양수가 왼쪽**이다(`SeraPatrol.SetFacing` 주석).

Z 각 = `atan2(d.y, d.x) − 90°`. 근거는 위 17-B 의 「회전 0 = **위(+Y)**」다 (2026-09-24 실측으로 부호가 뒤집혔다).
`turnDegreesPerSecond` 360 으로 부드럽게 돈다(0 이면 즉시).

> ⚠ **월드 회전을 직접 쓴다.** 세라는 좌우를 `localScale.x` 부호로 뒤집는데, Point Light2D 의
> 행렬이 `TRS(position, rotation, outerRadius)` 라 **스케일을 통째로 버린다**(`Light2D.cs:565-573`).
> 그래서 부모가 뒤집혀도 빛은 따라 뒤집히지 않는다. `SeraVisionDisplay` 가 반전을 물려받지 않으려고
> 메시를 형제로 띄우는 것과 같은 문제를, 여기서는 회전으로 풀었다.

- **감정 ID 5종은 `CharacterSpriteData.asset` 등록값이 전부다** (CLAUDE.md §0-4). 지어내지 않는다.
- `low_whisper` 는 **아직 어느 yarn 도 부르지 않는다.** 슬롯만 있다.
- `frozen` 은 **의도적으로 영원히 부르지 않는다** — 2회차 복선(`House_Opening.yarn:90`).
- 등록 목록에 없는 ID 가 오면 **경고를 남기고 현재 빛을 유지**한다. 조용히 버리지 않는다(§0-7).

> ⛔ **인형화·발각 진행도에 연동하지 않는다.** CLAUDE.md §7 이 인형화를 **어떤 형태로도** 표시하지
> 못하게 했고 전달 채널을 다섯(진실의 거울 · 손가락 마디 · 쿠루 태도 · 딱딱 소리 · 그림자 토끼 색)으로
> 열거했는데 세라의 빛은 거기 없다. 발각 2초도 「루의 그림자 하나로」 못박혀 있다(`SeraVision.cs`).
> **이 연동을 나중에 추가하지 말 것.**

> ⚠ **`yieldToBadEnding` 은 꺼져 있다.** 이 빛은 `BadEndingDirector` 가 모는 조명(`거실 조명`)이
> 아니고, 배드 엔딩에서도 세라의 기분은 바뀌기 때문이다(`House_BadEnding.yarn` 의 `warm_smile` 2건).
> 이 컴포넌트를 `거실 조명` 에 붙일 일이 생기면 그때는 켠다.

> ⚠ **`anchor` 는 비어 있다 — 비워 두는 것이 맞다.** 빛이 세라의 **자식**이라 위치는 부모를 따라
> 저절로 간다. `anchor` 는 빛을 세라 밖에 둘 때만 쓴다.

**마을(MapScene) — 2026-09-24 배선 완료.** 문서에 「마을에는 빛이 없다」고 적혀 있었지만
**사실과 달랐다**: `세라` 밑에 자식 `Spot Light 2D` 가 **이미 있었다**(Point · 세기 1 ·
바깥 반경 0.5625 · 각 360/360). 집 쪽 빛의 복제본이다. 없던 것은 빛이 아니라

### 17-B-5. 밤에 색이 죽는다 🟡 (2026-09-25 · 임시값으로 두고 보류 · **근본 해결은 밤 팔레트**)

**증상**: 밤 구간에서 도트 고유색이 안 읽힌다. **세라만이 아니라 밤에 나오는 모든 아트가 같이 죽는다.**

#### 원인 — 버그가 아니다

`Night Global Light 2D` 는 블렌드 **0 = Multiply** 다. 세기를 곱하면 채널 차이도 같은 비율로
줄어, 8비트 화면에서 색이 뭉개진다. **어떤 방법으로 어둡게 하든 똑같다** — 곱셈이든 그레이딩이든.
채도는 별로 안 줄고 **채널폭(절대 색 차이)이 준다.** 그게 체감의 정체다.

> ⚠️ HDR 켜짐(`m_SupportsHDR: 1`), 그레이딩 LDR(`m_ColorGradingMode: 0`). 정밀도 문제가 아니다.

#### ⛔ 전역광을 끄면 더 어두워진다 — 없애는 건 답이 아니다

URP 2D 에서 전역광은 **유일한 광원**이다. 끄면 Lit 스프라이트가 빛을 아예 못 받는다.

| 전역광 | 루의 방 명도 / 채널폭 | 정원 명도 / 채널폭 |
|---|---|---|
| **끔** | 129.9 / 13.0 | **53.0 / 0.0** (암흑) |
| 0.20 (원래) | 149.3 / 14.7 | 146.7 / 15.7 |
| **0.28 (현재)** | 153.7 / 15.1 | 174.2 / 18.7 |
| 0.45 | 161.2 / 16.1 | 222.1 / 24.7 (원본 PNG 수준) |

**전역광은 「어둡게 만드는 것」이 아니라 「보이게 만드는 것」이다.** 올릴수록 색이 산다.

#### 현재 값 — 임시다

| 무엇 | 값 |
|---|---|
| `Night Global Light 2D` | **흰색 · 세기 0.28 · Multiply** |
| 세라의 빛 | 평상 0.028 / `warm_smile` 0.14 / `door_gap` 0.252 / `low_whisper` 0.021 / `frozen` 0.035 |
| `…▸ 밤 색보정` Volume + `Assets/Settings/NightGradeVolumeProfile.asset` | `ShadowsMidtonesHighlights` 그림자 1.15 · 중간톤 1.03 |

> 🔑 **전역광과 세라의 빛은 항상 같은 비율로 움직인다.** 0.20 → 0.28 로 올릴 때 세라의 빛도
> ×1.4 했다. 그래야 「평상은 있는 듯 없는 듯, 켜지면 도드라진다」는 대비가 어느 밝기에서도 같다.
> 실측: 평상 대비 `warm_smile` **1.112배** · `door_gap` **1.086배**.
> **밝기를 바꿀 일이 생기면 반드시 둘 다 같은 비율로 바꾼다.**

> ⚠️ **0.28 은 눈에 띄게 고친 값이 아니다.** 0.20 대비 채널폭 +20% 수준이라 체감이 작다.
> 「밤 느낌」과 「색」 사이의 중간값으로 잡아 둔 것이고, **판정은 배경 아트가 실제 도트로
> 바뀐 뒤에만 가능하다.** 지금 더미에 맞춰 더 깎으면 두 번 일한다.

#### 🔵 근본 해결 — 밤 팔레트 대응표 (LUT). 도트를 다시 그리는 게 아니다

어둡게 **만드는** 대신 「어둡지만 채도 있는 색」으로 **바꾸면** 어둠과 색을 둘 다 얻는다.
도트 게임의 정석이고, **작업은 그림이 아니라 색표 한 장**이다.

**이 프로젝트는 팔레트가 이미 10색으로 확정돼 있다** — `Assets/Art/_palette/무채색낙원.gpl`:

| 환상(F) | | 현실(R) | |
|---|---|---|---|
| `F_cream` | #F9F2E4 | `R_gray` | #92938D |
| `F_light` | #FDD070 | `R_dust` | #373420 |
| `F_accent` | #CEE13D | `R_green` | #415641 |
| `F_orange` | #E88D32 | `R_teal` | #26403C |
| `F_brown` | #6D542B | `R_dark` | #091419 |

그래서 필요한 것은 **「밤에는 이 10색이 각각 무슨 색이 되는가」 10줄**뿐이다.
표가 나오면 LUT 로 구워 `ColorLookup` 볼륨 오버라이드로 물린다 —
**밤 색보정 볼륨이 이미 서 있으므로 거기 하나 추가하면 끝이다.** 코드 수정 없음.

> 참고: 현실(R) 5색이 이미 어둡고 채도가 있다. 밤 팔레트의 출발점으로 쓸 만하다.

#### ⛔ 안 되는 것으로 확인된 것들 — 다시 시도하지 말 것

| 시도 | 결과 |
|---|---|
| `ColorAdjustments.saturation +40` | **더 나빠졌다**(6.3%). 문제가 채도가 아니라 「어둡다」는 것이기 때문. 게다가 이 축은 `PostProcessingController` 가 설정 슬라이더·인형화 글리치로 이미 쓴다 |
| 「달빛」 푸른 틴트 | **어디서도 색을 개선하지 못했다.** 배경 더미가 따뜻한 갈색이라 차가운 빛이 R 을 눌러 더 납작해진다 |
| 가산(Additive) 블렌드 | 그림자를 없앤다. 측정 표본이 8,440 → 19,950px 로 늘어난 것이 증거 |
| 스플릿토닝 | 효과 없음 |
| 전역광 끄기 | 더 어두워진다 (위 표) |

> ⛔ **달빛 색은 넣지 않기로 했다 (2026-09-25 사용자 판단).** 정본 D S#01 은 「달빛만 비치는
> 어두운 방」이지만, **이 게임에서 빛의 주체는 세라**다. 앰비언트가 색을 가지면 광원이 하나 더
> 생기는 셈이라 그 장치가 희석된다. 전역광은 색 없는 흰색 — 「빛」이 아니라 **어둠의 정도**로만 쓴다.

#### ⚠️ 측정 함정 — 이것 때문에 오래 헤맸다

1. **촬영 카메라에 `UniversalAdditionalCameraData`(후처리 켬) 를 붙여야 한다.**
   `Camera.CopyFrom` 은 그 컴포넌트를 복사하지 않는다. 안 붙이면 그레이딩이 안 찍혀
   **비교 불가능한 숫자**가 나온다. 이 세션 전반부 수치(5.6% → 7.5% 류)가 전부 그랬다.
2. **인물 하나로 씬 전체를 판정하지 말 것.** 세라(혼합 팔레트)와 배경(따뜻한 갈색)은
   같은 조명에 **반대로** 반응한다. 세라만 보고 정했다가 배경이 나빠진 일이 있었다.
3. **원본 PNG 와 렌더를 비교할 때 같은 대상을 재라.** 원본은 불투명 픽셀만, 렌더는
   배경을 제외한 픽셀만. 안 그러면 「채도 17.9% → 3.0%」 같은 헛숫자가 나온다.
4. `PixelPerfectCamera` 의 커스텀 투영 행렬도 `CopyFrom` 으로 딸려온다. `ResetProjectionMatrix()` 필요.

### 18-B. ⚠ 카메라를 다시 만질 때 알아야 하는 것

**바운드가 화면보다 작으면 카메라가 움직이지 않습니다.** 버그가 아니라 Cinemachine 의 동작입니다.

```
theoreticalMax = max(바운드가로 ÷ 1.7778, 바운드세로) ÷ 2
ortho >= theoreticalMax  →  해가 중점 한 점으로 무너져 카메라 고정
```

(`ConfinerOven.cs:265-267` · `:371` `theoreticalMaxCandidate`. `OversizeWindow` 가 꺼져 있을 때)

| 대상 | 바운드(월드) | tmax | 적용 ortho | 결과 |
|---|---|---|---|---|
| 루의 방 | 6.41 × 7.97 | 3.983 | 2.8125 | 추적 |
| 다락방 | 6.98 × 4.68 | 2.341 | 1.875 | 추적 |
| 학교 문 (2) | 54.80 × 54.66 | 27.33 | 5.625 | 추적 |
| MapScene `SceneCameraBounds` | 47.70 × 63.52 | 31.76 | 5.625 | 추적 |
| Shelter `SceneCameraBounds` | 7.00 × 6.00 | 3.00 | 5.625 | **중앙 고정 (의도)** |

- ⚠ **`루의 방` 루트는 Z축 90° 회전입니다.** 씬 YAML 의 `m_Size` 에 스케일을 곱하면 축이 뒤바뀝니다.
  `Collider2D.bounds`(월드 AABB)로 재세요.
- 적용할 ortho 는 **`5.625 / N`(N=정수)만** 쓸 수 있습니다(CLAUDE.md §11 줌 절).

**씬 기본 바운드 — 이름 규약 `SceneCameraBounds`**

- `CameraFollow.SetBound(null)` 은 이제 "바운드 없음" 이 아니라 **"방을 나간다"** 는 뜻이고,
  씬 기본 바운드로 되돌아갑니다. 호출자 5곳이 전부 그 뜻입니다.
- 씬 루트에 **이 이름의 GameObject + `BoxCollider2D`(반드시 `isTrigger`)** 를 두면
  씬 로드 때 자동으로 잡힙니다. 인스펙터에 직접 꽂지 않아도 됩니다
  (참조가 씬과 함께 파괴되므로 이름으로 다시 찾습니다).
- 현재 있는 씬: **MapScene · Shelter**. **Home 에는 없습니다** — 본채와 다락방이
  (−5, 4) 와 (−197, 113) 으로 떨어져 있어 사각형 하나로 덮이지 않고, 방 안은 `roomBound` 가 처리합니다.

**Point `Light2D` 반경은 트랜스폼 스케일을 따라가지 않습니다**

`Light2D.GetMatrix()`(URP `Runtime/2D/Light2D.cs:565-573`)가 **Point 타입일 때만**
`TRS(position, rotation, outerRadius)` 로 행렬을 새로 만들어 스케일을 통째로 버립니다.
Freeform·Sprite·Parametric 은 `localToWorldMatrix` 를 쓰므로 영향이 없습니다.
→ 월드 배율을 바꾸면 **Point 라이트 반경은 직접 곱해야 합니다.**

**씬의 뷰포트 `y 0.125 / height 0.75` 는 손으로 넣은 값이 아닙니다**

`PixelPerfectCamera` 는 `[ExecuteInEditMode]` 라 에디터에서도 매 프레임 `Camera.pixelRect` 를
Windowbox 값으로 다시 잡고, 씬을 저장하면 그 결과가 프리팹 인스턴스 오버라이드로 박힙니다.
**지워도 에디터에서 씬을 저장하면 다시 생깁니다. 결함이 아닙니다.**
런타임에는 `CameraFollow.LateUpdate` 가 `viewportRect`(0,0,1,1)로 되돌린 뒤 PPC 가 다시 잡으므로
실제 레터박스는 언제나 Windowbox 가 만듭니다.

> ⚠ 그 오버라이드를 `PrefabUtility.SetPropertyModifications` 로 걷어내면

| ① 평상 | 빛으로 된 얇은 판. 황금색이 **언뜻** 비칠 뿐이며 자세히 봐야 안다. 걷는 동안 한 번만 스치고 아무도 반응하지 않는다 |
| ② 접촉 | 쿠루가 열쇠를 댄 **자리 주변만** 드러난다. 세라의 결계 점검(F-6-1)과 같은 원리다. ③과 구분돼야 하므로 범위·지속을 크게 쓰지 않는다. **켜지는 자리는 `Forest_Barrier_Arrival` 과 `Forest_Barrier_KeyCheck` 사이**(정본 문단 1238)이며, 앞 노드에서 켜면 루의 「아무것도 안 보이는데요」와 화면이 어긋난다 |
| ③ 강화 | **전면 가시화.** 이 상태로 데모가 끝난다 |

> ⚠ **카메라 정사영 크기를 바꾸지 않는다.** ③ 이 화면 안쪽으로 밀려오는 것은 스프라이트
> `localPosition` 오프셋(`Reinforced Push In`)으로만 만든다. 줌으로 당기면 픽셀 정수배가 깨진다(F-6 · §11).

### 21-D. SFX 3종 🔴 (4번 AudioManager 선행)

**이름을 지어내지 않았다.** AudioManager 에 실제로 등록한 뒤 그 이름을 인스펙터에 적는다
(CLAUDE.md §4 「이름의 출처」). 비어 있으면 무음으로 넘어간다.

| 필드 | 정본 표기 | 비고 |
|---|---|---|
| `Sfx Owl` | 부엉이 울음 **「후우」** | 대사창을 쓰지 않고 SFX 로 처리한다(F-4-4). **표기는 고정이다.** S#01 의 부엉이 SFX 재활용 가능 여부는 F 에서 확인 중 |
| `Sfx Reinforce` | 결계가 강화되는 소리 | 정본에 표기 없음. 넣을지도 판단 대상 |
| `Sfx Clicking` | **딱딱.** 두 번 | 다시 걷기 시작하는 순간에 맞춘다(C-7-2 숲 후반). 「분노 이후의 당혹감」과 같은 강도이며 **새 강도를 만들지 않는다** |

> ⚠ 부엉이는 **돌아본 자리가 아니라 그 뒤에** 운다. 아무것도 없다는 공백을 먼저 두고,
> 공백이 끝난 다음에 소리가 난다. 디렉터가 그 순서로 돼 있으니 `Empty Beat Duration` 을
> 0 으로 만들지 말 것.

### 21-E. 종료 화면 — 씬을 만들지 않는다 ✅

검은 화면에 `인형화 00%` 한 줄은 **디렉터가 런타임 캔버스로 만든다**(sortingOrder 1000,
`TransitionManager` 암전 999 위). 씬도 프리팹도 필요 없고 Build Settings 도 그대로다.

> ⚠ **`CreditsScene` 을 `Next Scene` 에 넣지 말 것.** 정본 `[UI]` 가 「크레딧을 올리지 않는다」이고,
> `CreditsManager` 는 크레딧을 스크롤한 뒤 결과를 띄우는 화면이라 어긋난다. 기본값은 `TitleScene` 이다.
>
> `Next Scene` 을 **비우면** 종료 화면을 띄운 채 멈춘다. 「종결이 아니라 정지」를 그대로 두고
> 싶을 때의 선택지이며, 그때는 사람이 창을 닫는 것이 데모의 끝이 된다.

### 21-E-2. 강화 연출 수치 🟡 (화면 확인)

정본 1259 의 여섯 단계가 인스펙터 값으로 열려 있다. **화면을 보고 맞추는 것이 맞다** —
아래는 시작값이며 실측으로 정한 값이 아니다.

| 단계 | 필드 | 시작값 |
|---|---|---|
| ① 눈에 들어온다 | `Reveal Alpha` | 0.22 |
| ② 푸른빛을 튕겨낸다 | `Repel Flash Alpha` · `Repel Glitch Duration` · `Repel Shake` | 0.6 · 0.45 · 0.35 |
| ③ 열쇠 회수 | `Recover Slowmo Scale` · `Kuru Step Back` | 0.45 · 0.35 |
| ④ **눈이 부실 만큼** | `Surge Peak Alpha` · `Surge Duration` · `Surge Shake` | 0.92 · 1.6 · 0.6 |
| 잔광 | `Afterglow Alpha` | 0.18 |
| ⑤ 물러섬 | `Pair Step Back` | 0.6 |
| ⑥ 고개 올리기 | `Look Up Delay` | 0.7 |

> ⚠ `Surge Peak Alpha` 가 높아도 되는 것은 **순간**이기 때문이다. 거기서 오래 머물면 안 된다 —
> 두꺼워지는 것은 결계이지 화면이 아니다.
> ⚠ `Afterglow Alpha` 는 이후 대사가 그 위에 뜬다. 너무 높으면 글자가 묻힌다.
> ⚠ **줌을 쓰지 않는다.** 흔들림만 쓴다. 정사영 크기를 바꾸면 픽셀 정수배가 깨진다(§11).

### 21-F. 손대지 말 것 ❗

- **`<<jump>>` 를 노드에 박지 않는다.** 디렉터가 다섯을 순서대로 부르고 사이에 열쇠 접촉·무음·
  강화·돌아보기·부엉이를 끼운다. jump 를 박으면 그 자리가 사라진다
- **노드를 합치지 않는다.** `Arrival` / `KeyCheck` 가 나뉜 것은 그 사이에서 ② 를 켜기 위해서다
- **세라 스프라이트를 세우지 않는다.** 목소리만 나오며 이름도 포트레이트도 띄우지 않는다
  (E-62-4 · F-7-5). 화자 ID `세라목소리` 가 그 처리를 맡는다
- **루가 저항하는 동작을 넣지 않는다.** 필터가 환상으로 덮이는 것을 그대로 둔다. 저항을 넣으면
  루가 상황을 파악한 것이 되어 은폐 축이 무너진다
- **인형화 분기를 만들지 않는다.** E-62-3 에서 폐기됐고 대사는 한 벌이다. 31 을 넘긴 플레이어도
  같은 대사를 보며, 넘긴 결과는 종료 화면의 수치로만 남는다
- **「잠겼다」는 UI 표시를 두지 않는다.** 토글이 그냥 듣지 않을 뿐이다(정본 ▶조작)
