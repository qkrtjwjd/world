**배치 플레이모드 요령 (전부 실측으로 겪은 것)**
- `WaitForEndOfFrame` 이 오지 않는다 → `ScreenCapture` 대신 `Camera.Render` → RenderTexture 로 찍는다. UI 오버레이는 안 찍히므로 알파를 로그로 잰다.
- 프레임이 매우 빨라 `Rigidbody2D.MovePosition` 을 매 프레임 부르면 물리 스텝마다 한 번만 반영된다 → `WaitForFixedUpdate` 단위로 옮긴다.
- MapScene 을 바로 열면 `DaggerFilter` 프리팹(Home 소속)이 없다 — 드라이버에서 Instantiate. 집 구간 플래그 13개를 켜지 않으면 Home 로드 때 S#01 이 돈다.
- 로그 요약 때 「마침표로 안 끝나는 줄」을 거르지 말 것 — 대사를 놓친다.
- 그림 확인만이면 플레이모드 없이 `-executeMethod` 로 텍스처를 PNG 로 덤프한다(1분).
- ⚠ 런타임에 만든 오브젝트를 `Destroy` 한 **같은 프레임에 `LoadScene`** 하면 Unity 가 멈춘다(2026-09-30 재현 2회). 씬과 함께 사라지게 둔다.
- 촬영 카메라로 색을 잴 때는 `UniversalAdditionalCameraData`(후처리 켬)를 붙이고 `ResetProjectionMatrix()` — `Camera.CopyFrom` 은 둘 다 챙기지 않는다.

## 4. 렌더링 · 화면

### 4-1. 색각 보정 · 화면 조정 ✅

- 색각 보정: `ColorblindRenderFeature` 가 URP 렌더러(`Asset 1_Renderer`)에 등록 · `ColorblindCorrect.mat` 연결. **모드 0(기본)이면 패스를 걸지 않는다.** UI(Overlay)는 보정에서 제외되는 것이 정상.
- 화면 조정: `GameManager ▸ Volume_Screen`(Global · **weight 1** · priority 0) + `ScreenAdjustVolumeProfile.asset`. 프리팹 안이라 네 씬에 따라 들어간다.
  - ⚠ **weight 는 1 이어야 한다**(코드가 이 볼륨 weight 를 건드리지 않는다). **priority 0 은 의도** — MapScene 글리치 볼륨(10)의 인형화 회색화가 사용자 채도에 덮이지 않게.
- `m_RendererFeatureMap` 은 손대지 않는다 — 개수가 어긋나면 URP 가 열 때 다시 만든다.
- 🟡 화면으로 한 번 볼 것: 설정 ▸ 색맹 모드 4종 전환 · 밝기 · 채도 슬라이더.
