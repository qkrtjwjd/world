# 일러 컷 파일명 — 코드가 찾는 이름 그대로

규격서 8장 「일러 컷」의 12장이다. **전부 640×360 전면**이고, 12개 모두 환상 필터다.

## 넣는 법

`Assets/Resources/CG/` 에 아래 파일명 그대로 png 를 넣으면 끝난다.
경로도 이름도 코드가 그대로 찾으므로 다른 배선은 필요 없다.

```
Assets/Resources/CG/sera_door_eye.png
Assets/Resources/CG/lu_porcelain_hand.png
...
```

## 부르는 법 — Yarn

```
<<show_cg "sera_door_eye">>
… 대사 …
<<hide_cg>>
```

⚠ **그림이 없으면 아무 일도 일어나지 않는다.** 경고 한 줄만 남기고 컷을 건너뛴다.
포트레이트와 같은 방침이다 — 아트가 없다고 대사가 멈추면 안 되기 때문이다.
그래서 **원고에 `show_cg` 를 미리 넣어 두어도 안전하다.**

## 12장

| # | 파일명 | 규격서 설명 |
|---|---|---|
| 1 | `sera_door_eye` | 세라 — 문틈의 눈. 얼굴 말고 눈만. 빛나는 건 아주 약하게 |
| 2 | `sera_tuck_hand` | 세라 — 이불 여미는 손. 동작은 부드러운데 이불이 목까지 올라온다. **다정한 거랑 가두는 게 같은 그림이어야 한다** |
| 3 | `sera_light_suppressed` | 세라 — 손끝의 빛이 억눌림 |
| 4 | `sera_pulled_hand` | 세라 — 걸음 멈추고 손끝이 당겨짐. 마을 1회차 끝나기 직전 |
| 5 | `lu_porcelain_hand` | 루 — 도자기 손. 손가락 두 마디. 달빛에 질감이 다르게 반사된다 |
| 6 | `lu_hug_coat` | 루 — 코트를 끌어안음. 얼굴 묻지 않는다. 그냥 팔로 감싸는 정도 |
| 7 | `lu_pocket_hand` | 루 — 주머니 더듬는 손 |
| 8 | `lu_grip_dagger` | 루 — 단검 쥐는 손 |
| 9 | `kuru_door_face` | 쿠루 — 문틈의 얼굴. 입은 웃는데 눈은 안 웃는다. 절반만 보인다 |
| 10 | `sugarcube_palm` | 각설탕 — 손바닥 위 |
| 11 | `ending_sera_hand` | 감금 엔딩 — 세라가 손을 잡음 |
| 12 | `ending_door_locked` | 감금 엔딩 — 방문이 잠김 |

## 규격

| | |
|---|---|
| 크기 | **640 × 360** (캔버스 기준 해상도와 같아 1:1 로 뜬다) |
| 비율 | 16:9 |
| 도트 여부 | **도트 아님.** 크게 그려도 되고 최종 비율만 16:9 로 맞추면 된다 |
| 필터 | 전부 환상. 컷씬 동안 필터 토글이 잠기므로 **한 벌만** 그린다 (규격서 6장) |
| 파일명 | 영문 소문자 + 언더바 (규격서 7장) |

## 배선 (이미 되어 있음)

- `Assets/Scripts/UI/CutsceneCGView.cs` — 전면 캔버스를 필요할 때 만들고 컷을 띄운다.
  `GameManager` 프리팹에 붙어 있어 모든 씬에 존재한다.
- `Assets/Scripts/Dialogue/YarnCommandBridge.cs` — `show_cg` · `hide_cg` 커맨드.
- 캔버스 `sortingOrder 200` — 대사창보다 위, 저장 토스트(120)보다도 위다.
