# 집 구간 소품 — 그릴 목록

**무채색 낙원 · 데모** · 2026-09-18 · `Home.unity` 에서 직접 계산

씬에 들어 있는 더미 오브젝트의 **실제 크기를 재서 뽑은 목록**이다.
여기 적힌 도트 크기로 그리면 씬에서 크기를 조정할 필요가 없다 — 같은 이름으로 넣으면 그대로 맞는다.

---

## 0. 먼저 알아둘 것

| | 값 |
|---|---|
| 1 칸 (1 월드유닛) | **32 도트** |
| 화면 | 640 × 360 도트 |
| 피벗 | **Center** (배경·타일·오브젝트) · 캐릭터만 바닥중앙 |
| 넣는 곳 | `Assets/Art/` 아래 아무 데나 — 도트 임포트 설정이 자동으로 걸린다 |
| ⛔ 넣으면 안 되는 곳 | `Assets/Images/` — PPU 100 짜리 옛 폴더 |
| 팔레트 | `Assets/Art/_palette/무채색낙원.gpl` (Aseprite·Krita·GIMP) |

> **크기는 「이 정도로 그려라」가 아니라 「씬이 지금 이 크기로 쓰고 있다」는 뜻이다.**
> 더 크게 그리고 싶으면 씬에서 스케일을 바꾸면 되지만, 그대로 그리는 게 제일 편하다.

> **가구는 한 칸에 안 들어간다.** 쇼파는 118 도트 = 거의 4칸이다.
> 「32×32 물건」으로 생각하면 안 된다 — 타일 격자가 32일 뿐이고 가구는 여러 칸을 덮는다.

## 1. 타일 12종 — 32 × 32 고정

`Assets/Art/Tiles/House/_dummy/` 에 **같은 이름으로 덮어쓰면** 끝난다.
타일 에셋(`.asset`)이 이 PNG 를 보고 있어서 다른 배선이 필요 없다.

| 파일명 | 무엇 |
|---|---|
| `house_floor_wood.png` | 바닥 — 나무 |
| `house_floor_wood_alt.png` | 바닥 변형 (같은 나무의 다른 결) |
| `house_rug.png` | 러그 |
| `house_wall.png` | 벽면 — **위쪽 벽에만 쓴다** |
| `house_wall_top.png` | 벽 윗단 |
| `house_baseboard.png` | 걸레받이 |
| `house_ceiling_edge.png` | 천장 경계 |
| `house_corner.png` | 모서리 |
| `house_door_frame.png` | 문틀 |
| `house_window.png` | 창문 |
| `house_stair.png` | 계단 |
| `house_shadow.png` | 그림자 (반투명) |

> ⚠ **탑다운이라 벽면으로 그리는 것은 위쪽 하나뿐이다.**
> 좌·우는 가장자리, **아래쪽은 그리지 않는다** — 앞벽을 그리면 방 안이 가려진다.
> `현관벽` · `벽 (3)` 은 통행을 막는 콜라이더 줄이지 그려질 벽이 아니다.

## 3. 우선순위

데모가 지나가는 순서이자, 화면에 오래 머무는 순서다.

1. **타일 12종** — 이게 깔려야 방이 방으로 보인다. 소품보다 먼저
2. **부엌** — 데모에서 제일 오래 머무는 방 (S#04 전체)
3. **거실** — 현관 손잡이 4회 · 탐색 구간
4. **루의 방** — 오프닝. 밤이라 어두워서 디테일이 덜 보인다
5. **다락방** — 「상자 하나만」이라 물량이 적다
6. 세라의 방 · 유의 방 — 탐색 중 잠깐
7. 마당 · 정원

## 4. 두 벌이 필요한 것

환상/현실 필터로 **같은 자리에서 바뀌는 오브젝트**다. 정본이 **「색과 질감만 바꾸고 배치는 건드리지 않는다」** 고 못박았으므로, 형태를 다시 그리지 않고 색만 바꾼다.

| 환상 | 현실 |
|---|---|
| `거실 ▸ 책상` | `거실 ▸ 책상 (1)` |
| `다락방 ▸ 성년마네킹` | `다락방 ▸ 성년마네킹 (1)` |
| `부엌 ▸ 냉장고` | `부엌 ▸ 냉장고 (1)` |

팔레트 대응은 `무채색낙원.gpl` 을 보라.

| 역할 | 환상 | 현실 |
|---|---|---|
| 가장 밝은 면 | `#F9F2E4` | `#92938D` |
| 빛 (기본 바탕) | `#FDD070` | `#373420` |
| 포인트 | `#CEE13D` | `#415641` |
| 따뜻한 강조 | `#E88D32` | `#26403C` |
| 가장 어두운 면 | `#6D542B` | `#091419` |

## 5. 그리고 나서

1. `Assets/Art/` 아래에 PNG 를 넣는다 — 임포트 설정은 자동
2. 타일은 `_dummy/` 의 같은 이름을 덮으면 즉시 반영
3. 소품은 씬에서 해당 오브젝트의 SpriteRenderer 에 꽂는다
4. **판정은 게임 화면(640×360)에서 한다.** 확대해서 보면 영원히 마음에 안 든다
