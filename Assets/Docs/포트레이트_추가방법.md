# 포트레이트 추가 방법

**무채색 낙원 (world)** · 최종 갱신: 2026-08-04

대사 중 화면에 뜨는 캐릭터 그림(포트레이트)을 추가하는 절차입니다.
**배관은 이미 다 연결돼 있습니다. 그림만 넣으면 즉시 뜹니다.**

---

## 0. 지금 상태

| 항목 | 상태 |
|------|------|
| `Resources/PortraitConfigs/` (배치 방향·등장 연출) | ✅ 8종 생성 완료 |
| `Date/Dialogue/CharacterSpriteData.asset` (감정별 그림 슬롯) | ✅ 생성 + 프리팹 연결 완료 |
| **실제 그림 파일** | ❌ **한 장도 없음** |

그래서 현재는 대사 텍스트만 나오고 인물 그림은 안 뜹니다.
Play 중 콘솔에 이런 경고가 뜨는 게 정상입니다.

```
[YarnCommandBridge] 스프라이트 없음: 루_neutral — Resources/Sprites/루_neutral 도
CharacterSpriteData 도 비어 있습니다. 추가 방법: Assets/Docs/포트레이트_추가방법.md
```

이 경고는 **같은 키당 한 번만** 뜹니다. 그림을 넣으면 그 키의 경고가 사라집니다.

---

## 1. 그림 넣는 법 — 두 가지 중 아무거나

두 경로 다 지원하며, **Resources 쪽이 먼저 조회됩니다** (`YarnCommandBridge.cs:510`).

### 방법 A — 파일 이름만 맞춰서 폴더에 넣기 (권장 · 유니티 조작 불필요)

`Assets/Resources/Sprites/` 에 아래 이름으로 넣으면 끝입니다.

```
{캐릭터}_{감정}.png
```

예시:

```
Assets/Resources/Sprites/루_neutral.png
Assets/Resources/Sprites/세라_warm_smile.png
Assets/Resources/Sprites/부엉이_perched.png
```

> ⚠️ 임포트 후 인스펙터에서 **Texture Type을 `Sprite (2D and UI)`로** 바꿔야 합니다.
> 기본값(`Default`)이면 `Resources.Load<Sprite>`가 못 찾습니다.

### 방법 B — CharacterSpriteData에 드래그

1. `Assets/Date/Dialogue/CharacterSpriteData.asset` 선택
2. `characters` 목록에서 캐릭터를 찾습니다
3. 해당 `emotionId`의 **Sprite 슬롯에 그림을 드래그**

그림 파일이 아무 폴더에 있어도 됩니다. Resources 밖이어도 무방합니다.

## 2. 지금 슬롯이 준비된 캐릭터·감정

`CharacterSpriteData.asset`에 빈 슬롯으로 미리 만들어 뒀습니다. **여기 없는 감정을 yarn에서 쓰면 안 뜹니다.**

| 캐릭터 | 감정 키 |
|--------|--------|
| **루** (오른쪽) | `neutral` `fearful` `suspicious` `dreamy` `eyes_closed` `alive_eyes` `angry` `blank_shock` `determined` `discomfort_hidden` `flustered` `holding_tears` `puzzled` |
| **세라** | `neutral_cold` `warm_smile` `low_whisper` `door_gap`※ `frozen`※ |
| **쿠루** | `neutral_observe` `low_observe` `closed_guard` `flustered` `smirk_memo` `stern` `glitch_real` `half_face`※ |
| **부엉이**※ | `perched` |
| **솔** | `neutral_flat` `subtle_pause` |
| **미루** | `working` `mannequin` |
| **아모** | `perfect_smile` |

※ = 오프닝/부엌 교체 시나리오용 신규. 아직 yarn에서 쓰이지 않습니다.

- `door_gap` — 문틈으로 눈만 보이는 세라 (S#02)
- `frozen` — 창밖을 보고 표정이 굳은 세라 (S#02)
- `half_face` — 문틈으로 절반만 보이는 쿠루. 웃지만 눈은 안 웃음 (S#04B)
- `perched` — 창틀에 앉아 루를 응시하는 부엉이 (S#01)

### 감정을 새로 추가하려면

`CharacterSpriteData.asset`의 해당 캐릭터 `sprites` 목록에 항목을 추가하고 `emotionId`를 적으면 됩니다. 방법 A(파일명)를 쓸 거면 이것조차 필요 없습니다.

## 3. 배치 방향 · 등장 연출

`Assets/Resources/PortraitConfigs/{캐릭터}.asset`에서 정합니다.

| 필드 | 뜻 |
|------|-----|
| `defaultSide` | `0` = 왼쪽, `1` = 오른쪽 |
| `entryMotion` | `0` SlideIn / `1` FadeIn / `2` None |
| `exitMotion` | `0` SlideOut / `1` FadeOut / `2` None |
| `entryDuration` `exitDuration` | 초 |

현재 **루만 오른쪽(1)**, 나머지 7종은 왼쪽(0)입니다.

yarn에서 `<<showSprite "루" "neutral" "left">>` 처럼 side를 직접 적으면 그쪽이 우선합니다. 생략하면 이 설정을 따르므로, **시나리오에 위치를 안 적어도 됩니다.**

> 캐릭터를 새로 추가할 때는 `Assets/Editor/PortraitConfigGenerator.cs`의 목록에 넣고
> 메뉴 `무채색낙원 ▸ 포트레이트 설정 에셋 생성`을 실행하면 에셋이 만들어집니다.
> (이미 있는 것은 건너뛰므로 여러 번 눌러도 안전합니다.)

## 4. `_real` 접미사 — 심리 게이지 연동

**심리 게이지가 70 이상이면** 같은 대사에서 자동으로 다른 그림으로 바뀝니다 (`YarnCommandBridge.cs:491-503`).

```
루_neutral        ← 평소
루_neutral_real   ← 게이지 70+ 일 때 자동 사용
```

`_real` 그림이 없으면 그냥 원래 그림을 씁니다. **선택 사항이며, 안 만들어도 아무 문제 없습니다.**

yarn에서 `<<showSprite "루" "neutral" "right" "fixed">>` 처럼 마지막 인자를 `fixed`로 주면 게이지와 무관하게 고정됩니다. 기존 yarn 대부분이 `fixed`를 쓰고 있습니다.

## 5. ⚠️ 알아둘 함정

### 감정 이름을 틀리면 엉뚱한 그림이 뜹니다

`CharacterSpriteData.GetSprite`(`CharacterSpriteData.cs:17-23`)는 요청한 감정을 못 찾으면 **그 캐릭터의 첫 번째 그림을 대신 반환합니다.**

```csharp
return sprites.Count > 0 ? sprites[0].sprite : null;
```

지금은 전부 비어 있어 null이라 티가 안 나지만, **그림을 채운 뒤에는 오타가 조용히 넘어갑니다.** `세라_warm_smilee`라고 잘못 쓰면 경고 없이 `neutral_cold`가 뜹니다.

그래서 목록의 **첫 번째 감정을 각 캐릭터의 무난한 기본 표정으로** 배치해 뒀습니다 (루 `neutral`, 세라 `neutral_cold`, 쿠루 `neutral_observe`, 솔 `neutral_flat`).

### 캐릭터 이름이 목록에 없으면 콘솔에 뜹니다

```
[CharacterSpriteData] '파란새' 캐릭터를 찾을 수 없습니다.
```

`파란새`는 폐기 예정인 드론 씬(`House_Night1.yarn`)에서만 쓰이므로 등록하지 않았습니다. 그 씬을 교체하면 사라집니다.

### 나레이션에는 원래 포트레이트가 없습니다

화자 이름 없는 묘사 줄은 Yarn Spinner가 이름창을 자동으로 숨기고, `showSprite`를 호출하지 않으면 그림도 안 뜹니다. **정상 동작입니다.**

## 6. 확인 방법

1. 유니티에서 `Assets/Prefabs/Dialogue.prefab`을 엽니다
2. `YarnCommandBridge` 컴포넌트의 **`Sprite Data` 슬롯에 `CharacterSpriteData`가 들어 있는지** 확인
3. Home 씬 Play → 대사 진행
4. 그림이 없으면 → 콘솔에 `스프라이트 없음: 루_neutral` 경고 (배관 정상)
5. 그림을 넣으면 → 그 경고가 사라지고 화면에 뜸
