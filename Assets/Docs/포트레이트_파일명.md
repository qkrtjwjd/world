# 포트레이트 파일명 — 코드가 찾는 이름 그대로

이 문서는 `Assets/Editor/PortraitMapGenerator.cs` 가 `Assets/Date/Dialogue/CharacterSpriteData.asset` 에서 뽑아 만든 것이다.
**감정 ID 를 늘리거나 바꾸면 이 표도 다시 뽑아야 한다.**

## ⚠ 규격서와 충돌하는 곳 — 먼저 읽을 것

코드가 찾는 키는 `Sprites/{화자ID}_{감정}` 인데 **화자 ID 가 한글**이다(`루` `세라` `쿠루` …).
그래서 `Resources` 경로로 넣으려면 파일명이 `루_neutral.png` 처럼 한글이 된다.
그런데 **규격서 7장은 「파일명은 영문 소문자에 언더바. 한글로 하면 유니티에서 깨지는 경우가 있어」** 라고 못박고 있다. 둘이 정면으로 어긋난다.

→ **아래 2번(에셋 슬롯)을 쓰면 이 충돌이 사라진다.** 슬롯에 꽂는 방식은 파일이 어디에 어떤 이름으로 있든 상관없으므로, png 는 규격서대로 영문으로 두면 된다.

## 넣는 법

1. `Assets/Resources/Sprites/` 에 아래 「파일명」 그대로 png 를 넣는다. 코드가 `Resources.Load` 로 먼저 찾으므로 에셋을 건드릴 필요가 없다. **단 파일명이 한글이 된다** — 위 충돌을 보라.
2. **(권장)** `Assets/Date/Dialogue/CharacterSpriteData.asset` 의 `sprite` 슬롯에 직접 꽂는다. png 파일명은 영문으로 자유롭게 둘 수 있다.

`_real` 은 **심리 게이지 70 이상**일 때 먼저 찾는 현실 버전이다. 없으면 기본 버전이 그대로 쓰인다 — 규격서 6장이 「캐릭터 두 벌은 루·세라·쿠루 셋만」이라고 했으므로 나머지는 `_real` 을 안 만들어도 된다.

아트가 하나도 없으면 초상화만 숨기고 **대사는 정상 진행**한다. 지금이 그 상태다.
